## Documentation Style Guide

### README.md
- **Purpose**: First introduction and getting started
- **Style**: Tutorial-style with working examples
- **Depth**: Basic to intermediate
- **Best for**: New users, quick setup

### QUICK_REFERENCE.md
- **Purpose**: Fast lookup and common patterns
- **Style**: Tables, short code snippets
- **Depth**: Concise, essential information only
- **Best for**: Experienced developers, copy-paste needs

### API_DOCUMENTATION.md
- **Purpose**: Complete technical reference
- **Style**: Detailed specifications
- **Depth**: Comprehensive, all parameters documented
- **Best for**: Understanding all options, type information

### vectorflow_logging.md
- **Purpose**: Technical logging reference
- **Style**: Structured log format examples
- **Depth**: Detailed log schemas
- **Best for**: Debugging, monitoring flows
